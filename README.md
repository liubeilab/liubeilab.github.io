# liubeilab.com

Static site for the Liu Lab, served by GitHub Pages from this repository. All
content lives **in this repo** — there is no server, no database, and no
external service. Pages are generated by one Node script; nothing is fetched at
page load.

Live site: <https://www.liubeilab.com/>

## Updating content

All content is plain files you (or Claude Code) edit, then rebuild.

| To change | Edit | Then |
|---|---|---|
| A paper | `data/publications.json` | `node build.mjs`, commit, push |
| A lab member | `data/team.json` | `node build.mjs`, commit, push |
| A past member | `data/alumni.json` | `node build.mjs`, commit, push |
| A resource link | `data/resources.json` | `node build.mjs`, commit, push |
| A news post | add a file in `news/` (see below) | `node build.mjs`, commit, push |
| Page copy / design | `build.mjs`, `assets/styles.css` | `node build.mjs`, commit, push |

GitHub Pages redeploys within about a minute of a push to `main`.

### Data files

- **`data/publications.json`** — newest first by `idx`. Fields: `idx` (running
  number, also shown on the page), `year`, `title`, `authors`, `journal`,
  `doi`, and `featured` (the one `true` entry leads the home page "Latest
  paper"). To add a paper, copy the top entry, bump `idx`, fill it in.
- **`data/team.json`** — sorted by `sortOrder` (leave gaps: 10, 20, 30… so
  someone can be inserted without renumbering). The first entry is the PI.
  `photo` is a path under `assets/img/people/`.
- **`data/alumni.json`** — sorted by `sortOrder`. `photo` under `assets/img/alumni/`.
- **`data/resources.json`** — grouped on the page by `category`, in `sortOrder`.

Add a member's photo by dropping the image in `assets/img/people/` and pointing
`photo` at it (any size; the layout crops to fit).

### News posts

One Markdown file per post in `news/`, named `your-slug.md` (the slug becomes
the URL `/news/your-slug/`). Front matter plus a Markdown body:

```markdown
---
title: "Our first microscope just arrived!"
date: 2022-11-14
excerpt: "A short one-line summary shown on cards and the home page."
cover: /assets/img/news/microscope.jpg
---
Body text in Markdown. Paragraphs, **bold**, _italic_, [links](https://…),
lists, and images:

![](/assets/img/news/microscope.jpg)
```

Put post images in `assets/img/news/`. Posts are ordered by `date` (newest
first). The build renders a card on `/news/` and a full page at `/news/<slug>/`.

## Building

```bash
node build.mjs
```

Requires Node 18+. No dependencies to install. The script reads `data/` and
`news/`, then writes every page (`index.html`, `research/index.html`, …, one
page per news post), plus `sitemap.xml`, `robots.txt`, `CNAME` and `404.html`.
The emitted `*.html` files are committed so the site works without a build step
on GitHub's side — always rebuild after editing content so they stay in sync.

## Structure

```
build.mjs           generates every page from data/ + news/ + the page copy here
data/*.json         publications, team, alumni, resources
news/*.md           one news post each
assets/styles.css   the whole design system
assets/nav.js       mobile navigation
assets/img/         hero + tool art, institutional marks, people/ alumni/ news/ photos
```

Eight top-level pages, each at its own URL:
`/` · `/research/` · `/technologies/` · `/open-science/` · `/publications/` ·
`/people/` · `/join-us/` · `/news/` (plus a page per news post).

## History

Content used to be served live from a Wix CMS. It has been migrated into this
repository (see `data/` and `news/`); the site no longer depends on Wix.
